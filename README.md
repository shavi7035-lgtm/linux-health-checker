# 🖥️ Linux System Health Checker

A Bash scripting project that displays important Linux system information such as CPU details, memory usage, disk usage, uptime, internet connectivity, running processes, and overall system health.

---

## 📌 Features

- System Information
- Current Date & Time
- Hostname
- Operating System
- Kernel Version
- System Uptime
- Memory Usage
- Disk Usage
- Logged-in Users
- Internet Connectivity Check
- CPU Information
- Running Process Count
- Health Summary
- Colored Terminal Output
- Basic Error Handling

## ▶️ How to Run

Make the script executable:

```bash
chmod +x health_checker.sh
```

Run the script:

```bash
./health_checker.sh
```
